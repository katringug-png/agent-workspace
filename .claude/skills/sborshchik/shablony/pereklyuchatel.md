# Образец переключателя агента

Кладу в `.claude/skills/<имя агента>/SKILL.md` внутри папки «Агенты».

Это **тонкий переключатель**: он только включает агента и отправляет читать его тело.
Само тело лежит в проекте агента — так оно не грузится в память, пока агента не позвали.

Имя навыка пишу строчными буквами, тем же словом, каким человек будет звать агента.

---

```
---
name: <имя строчными>
description: <Кто это одной фразой. Что делает. Использовать, когда пользователь говорит «<имя>, ...», «<пример фразы 1>», «<пример фразы 2>». Не использовать для <чужая задача> — это <другой агент или никто>.>
---

Это тонкий переключатель. Всё тело агента, шаги работы и правила — в
`проекты/<Имя>/agents/<имя>.md`.

Прочитай этот файл целиком и следуй ему как своей инструкции для текущего разговора:
`проекты/<Имя>/agents/<имя>.md`

Проектные правила и расположение файлов — в `проекты/<Имя>/AGENTS.md`.
```

---

## Про описание

Описание — единственное, по чему программа решает, звать агента или нет. Правила:

- **без двоеточий внутри текста** — двоеточие с пробелом после него ломает чтение шапки
  файла, и агент может молча не включиться. Вместо двоеточия ставлю тире;
- слова-зацепки из настоящих фраз человека, а не выдуманных;
- обязательная концовка «Не использовать для …» — иначе два агента будут драться за одну
  задачу и включаться будет не тот.
