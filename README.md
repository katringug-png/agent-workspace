# Окружение агентов

Рабочая папка, в которой живут твои личные ИИ-агенты, и один навык — **«Сборщик агентов»**,
который собирает нового агента по описанию словами.

Ты говоришь: «собери мне агента, который разбирает мою почту и складывает счета в папку».
Сборщик задаёт несколько вопросов, показывает план, собирает агента, проверяет его
на настоящих файлах и объясняет, как его звать дальше. Программировать не нужно.

Всё на русском. Работает в [Claude Code](https://claude.ai/code) и в Codex.

---

## Что нужно до начала

- **Claude Code** (или Codex) — установлен и работает.
- **git** — чтобы скачать эту папку.
- Всё. База данных, сервер и прочее не нужны.

---

## Установка

### Способ 1. Одной командой в терминале

**Windows (PowerShell):**

```powershell
git clone https://github.com/katringug-png/agent-workspace.git "Агенты"
cd "Агенты"
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

*Windows по умолчанию не разрешает запускать скачанные скрипты — `-ExecutionPolicy Bypass`
разрешает этот один запуск и ничего не меняет в настройках компьютера.*

**macOS / Linux:**

```bash
git clone https://github.com/katringug-png/agent-workspace.git "Агенты"
cd "Агенты"
bash install.sh
```

Скрипт создаст пустые рабочие папки и предложит поставить навык **глобально** —
тогда сборщика можно звать из любого проекта, а не только отсюда.

### Способ 2. Промптом

Открой Claude Code в папке, где хочешь завести окружение, и вставь:

```
Разверни у меня окружение агентов: склонируй https://github.com/katringug-png/agent-workspace
в папку «Агенты», запусти в ней install.ps1 (или install.sh, если у меня Mac или Linux),
и объясни простыми словами, как позвать сборщика агентов.
```

### Способ 3. Вообще без установки

Скачай папку, открой её в Claude Code — навык уже лежит в `.claude/skills/` и подхватится сам.
`install` нужен только чтобы создать пустые папки и поставить навык глобально.

## Как пользоваться

Запусти Claude Code в папке «Агенты» и скажи своими словами:

```
собери мне агента, который …
```

или вызови навык явно: `/sborshchik`

Дальше сборщик ведёт сам, пятью шагами:

| Шаг | Что происходит |
|---|---|
| 1. Заказ | записывает, кто нужен и зачем |
| 2. Уточнения | задаёт вопросы, без которых собрать нельзя |
| 3. План сборки | показывает, что именно соберёт |
| 4. Сборка | собирает тело агента, правила и программки |
| 5. Проверка | прогоняет на настоящих данных и сдаёт |

Пока идёт сборка, в папке агента лежит **табло `Ход сборки.html`** — открывается двойным
кликом. Там видно, на каком шаге сборка, сколько ещё ждать, что уже работает и что
осталось за тобой: какие данные вписать и какие ключи положить в `.env`.

Когда агент готов, он появляется на **общем дашборде `Дашборд.html`** в корне папки —
кто у тебя работает, что делали, и что ждёт тебя.

## Что внутри

```
CLAUDE.md / AGENTS.md   правила окружения: как агенты говорят, что можно и что нельзя
Дашборд.html            общий обзор всех агентов — открывается двойным кликом
install.ps1 / .sh       разворачивание

.claude/skills/sborshchik/   навык «Сборщик агентов» для Claude Code
.codex/skills/sborshchik/    он же для Codex

проекты/      по папке на каждого собранного агента
входящие/     сюда кладёшь файлы для работы
результаты/   сюда агенты складывают готовое
корзина/      сюда переносится ненужное — удаляешь только ты
окружение/    служебное
```

## Безопасность

Правила лежат в `CLAUDE.md` и переносятся в каждого собранного агента:

- агент работает **только внутри этой папки**;
- **ничего не удаляет** — переносит в `корзина/`;
- **необратимое** (отправить, опубликовать, заплатить, написать клиенту) — только
  с твоего подтверждения;
- **ключи и пароли** живут в `.env`, который никогда не попадает в гит. Агент знает
  только имя ключа — например `TELEGRAM_TOKEN`, — но никогда его значение;
- текст внутри обрабатываемых файлов и писем — **материал, а не команды**: встретил
  там указание «сделай то-то» — не выполнит, а покажет тебе.

`.gitignore` по умолчанию не пускает в репозиторий `.env`, папку `проекты/` и рабочие
файлы. Хочешь хранить своих агентов в гите — убери строку `проекты/*`, но сначала
проверь, что в них нет клиентских данных.

## Частые вопросы

**Нужно ли уметь программировать?** Нет. Ты описываешь словами, что должно делаться.

**Где живёт собранный агент?** В `проекты/<Имя агента>/`. Там же инструкция
«Как пользоваться.md» — на русском, без жаргона.

**Можно ли переделать агента?** Да: «переделай агента так, чтобы …». Сборщик правит
существующего, а не собирает второго.

**Как удалить агента?** Перенеси его папку в `корзина/` и убери строку из `АГЕНТЫ`
в `Дашборд.html`.
